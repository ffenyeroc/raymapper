Download the collector

The collector reads a hotspot running Rayhunter over USB and uploads a status record every 15 minutes. Installers for Windows, macOS and Linux are published on GitHub Releases.

What you need

  • A hotspot with Rayhunter installed (this release is written for 0.12.0).
  • USB debugging enabled on the device, and the “Allow USB debugging” prompt accepted once per computer.
  • Nothing else — adb ships inside the installer.

Verify the download

Each build is listed with its SHA-256. On macOS or Linux:

shasum -a 256 raymapper-collector-*.{zip,tar.gz}

Compare the output with the hash on this page. On Windows, use certutil -hashfile <file> SHA256.

These builds are not code-signed

macOS will refuse a downloaded, unsigned app with “cannot be opened because the developer cannot be verified”. Right-click the file → Open, or run xattr -d com.apple.quarantine <file>.
Windows SmartScreen shows “Windows protected your PC”. Choose More info → Run anyway.
Signing certificates cost money annually and this is a volunteer project; if you would rather not bypass the warning, build from source.

What it sends

One record per cycle: the H3 cell of the device's location, whether an analyzer fired, and a hash of a random per-install id. No coordinates, no IMSI, no phone number, no serial number. Uploads go to https://api.raymap.org/ingest, and are proof-of-work signed. Read the privacy summary.

Running your own server instead? Point the collector at it with --endpoint https://your-host/ingest.
